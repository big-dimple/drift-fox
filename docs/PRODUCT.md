# Drift Fox（雪地：北极狐）— 产品计划

> 状态：已定稿 · 2026-09-05 · 本文件是产品事实的单源，开发计划见 `docs/DEVPLAN.md`。

## 标语

- **主标语（跨平台合同）**：操控全速疾驰的北极狐，利爪抓雪贴地漂移，在雪原狂飙中犁开碎雪蓄满寒霜，下一秒借势蹬冰、飞越天险裂谷。
- **PC 商店页变体**：化身全速狂奔的北极狐，按住 Shift 利爪抓地切入低空贴雪漂移，撕开冰原蓄满寒气，瞬时蹬冰飞跃绝壁裂谷！

## 一句话卖点

贴地漂移系 + 环境互动：自动奔跑的北极狐按住 Shift 利爪抓地漂移，雪地犁出爪痕、喷出冷气蓄「寒气」，满格穿冰晶门飞跃裂谷。

## 核心循环（board-race 语法的狐语翻译）

1. 自动全速奔跑；
2. 按住 Shift 抓地漂移：切入弯心 + 爪痕刻进雪面 + 冷气积蓄寒气值；
3. 松开/踩点释放：直线爆发蹬冰；
4. 寒气满格 + 穿越冰晶门 = 飞跃裂谷。一局 **5 个**飞跃点，寒气**不分档**（满格才能飞跃，一句话讲得清）。

## 环境互动

- 本期全保留：松树林回转门、雪地扬尘尾迹、冰面裂纹 decal、白昼极光（原画合同：亮蓝白天天空中挂青绿极光帘）；
- 排期靠后：裂谷动态塌陷；
- 明确不做：真实毛发渲染、动态雪崩追逐、可破坏冰层物理。

## 美术风格

**街机雪原 = LowPoly 几何 × toon/cel 着色 × 极光色彩剧本。**
视觉锚点 = 原画：亮蓝白昼天空 + 青色极光帘 + 白雪蓝影 + 金色冰晶门（雪原蓝金对比）。继承 board-race 的 toonMaterial / edgePass / sky / postPipeline 渲染管线；狐狸辨识度靠剪影与色块（雪白主色、耳尖与爪部深色、大尾巴剪影，以原画为准）而非毛发；绝美来自色彩剧本与光（白昼极光、雪原蓝金对比、冰面色温），不靠贴图精度。明确不做手绘水彩质感、不做毛发、不做暗夜场景。

## 目标玩家与场景

先单人。手感成立后再评估双人分屏（board-race 双人体系很重，不搬）。单局时长对齐 board-race 一局节奏。

## 不做清单

多人、毛发、七个世界、渲染风格更换、内购、存档之外的元进度。

## 验收标准（什么叫资料片成立）

1. 桌面 + 844x390 横屏跑通 5 个飞跃点全程；
2. 爪痕 / 冷气 / 裂谷飞跃三件套截图人工评审通过；
3. 试玩者评价"比船更贴地更紧张"。
